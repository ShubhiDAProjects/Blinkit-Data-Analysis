# Blinkit-Data-Analysis
# 🛒 Blinkit Data Analysis | End-to-End Capstone Project

## 📌 Project Overview

This project focuses on analyzing Blinkit (online grocery delivery) data to uncover key business insights related to sales, customer behavior, and product performance. The goal is to simulate a real-world data analyst workflow by performing end-to-end analysis using multiple tools.

---

## 🎯 Objectives

* Understand customer purchasing patterns
* Identify top-performing products and categories
* Analyze the impact of ratings and pricing on sales
* Track sales trends over time (daily & monthly)
* Provide actionable insights for business decision-making

---

## 🛠️ Tools & Technologies Used

* **Python (Pandas, Matplotlib, Seaborn)** → Data cleaning & exploratory analysis
* **SQL** → Data querying and aggregation
* **Power BI** → Interactive dashboard & visualization

---

## 🔄 Project Workflow

### 1. Data Cleaning (Python)

* Handled missing values
* Converted data types (e.g., date, price)
* Created new features (e.g., food type, time-based columns)

### 2. Exploratory Data Analysis (Python)

* Sales trends (daily & monthly)
* Category-wise and city-wise analysis
* Rating and price relationship
* Top products and restaurants

### 3. SQL Analysis

* Aggregated key metrics (sales, orders, ratings)
* Performed group-by and filtering queries
* Extracted insights for dashboard building

### 4. Dashboard (Power BI)

* KPI cards (Total Sales, Avg Order Value, Avg Rating)
* Trend analysis (monthly & daily)
* Category & city performance
* Interactive filters and slicers

---

## 📊 Key Insights

* Identified top-performing cities and restaurants
* Certain categories contribute majority of revenue
* Ratings do not always correlate with higher sales
* Seasonal and time-based trends impact ordering behavior
